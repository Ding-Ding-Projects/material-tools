# Roadmap

## 0.1 — secure foundation

- [x] Frameless Material Design 3 shell.
- [x] Sandboxed renderer and typed read-only system-summary bridge.
- [x] Persisted language, funny-level, display-name, theme, density, accent, and emoji settings.
- [x] Bounded tab search and command palette regex foundation.
- [ ] Package and drive the first real unsigned Squirrel.Windows installer.
- [ ] Capture every foundation surface from the built artifact.

## 0.2 — application management parity

- [ ] Pin and validate all 227 upstream application entries.
- [ ] Detect WinGet, Chocolatey, installed package state, and available updates.
- [ ] Plan, confirm, install, uninstall, upgrade selected, and upgrade all.
- [ ] Stream progress, support cancellation, verify postconditions, and export logs.

## 0.3 — tweaks, AppX, configuration, DNS, and updates

- [ ] Implement all 67 upstream tweaks with exact detection and undo behavior.
- [ ] Implement all 33 AppX operations and provisioned-package handling.
- [ ] Implement all 33 configuration actions and 14 DNS providers.
- [ ] Implement every update policy and repair path.

## 0.4 — Win11 Creator

- [ ] Validate and copy source ISOs without modifying originals.
- [ ] Select editions, inject drivers, modify offline images, and export bootable media.
- [ ] Gate USB writing through the full destructive-action confirmation and recovery flow.

- [ ] Complete the hand-written universal-feature inventory across app and documentation site.
